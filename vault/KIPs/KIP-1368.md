## Summary

The Apache Kafka clients are often wrapped by frameworks such as Spring. Kafka does this itself in Kafka Streams and Kafka Connect. There is no architected way of identifying clients running within such frameworks which can hinder problem determination.

Two client configurations are added which can be set by frameworks embedding Kafka clients. These are flowed to the broker in the ApiVersions request alongside the client software name and version providing more comprehensive versioning information.
